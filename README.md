# Make the AI Judge Laugh: the Office Joke Open

One line of office comedy, 200 characters, judged head to head. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
